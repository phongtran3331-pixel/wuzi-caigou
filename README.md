# 物资采购管理

自管委员会策创部内部使用的物资采购管理网站：可创建多张采购表，在网页中直接增删改物资、一键直达商品链接、标记购买状态、采购人手写签名、标记是否可开发票，并自动汇总金额与进度。

## 功能

- **多张采购表**：左侧栏切换，可新建、重命名、删除
- **行内编辑**：物资名称、数量、说明、金额、链接均可直接在网页修改
- **链接直通**：自动从淘宝/拼多多分享文案中提取 URL，「直达」按钮一键打开商品页
- **购买标记**：勾选即记录购买日期，可按 全部/未购买/已购买 筛选
- **采购人签名**：手写板签名，签名图随清单展示
- **发票标记**：可开发票 / 不可开 / 待确认
- **汇总与导出**：预算/已购/待购金额、采购进度条、CSV 导出、打印
- **数据持久化**：数据保存在浏览器 localStorage，刷新不丢失

预置清单：拼豆活动物资采购（13 项，预算 ¥321.52）。

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui，纯前端静态站点。

## 本地运行

```bash
npm ci
npm run dev
```

## 部署

推送到 `main` 分支后，GitHub Actions 自动构建并发布到 GitHub Pages（见 `.github/workflows/deploy.yml`）。
